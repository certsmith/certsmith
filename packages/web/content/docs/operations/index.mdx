### 1. Persistent Storage
All cryptographic keys, certificates, BadgerDB state, and ACME account databases live under `/app/data`. It is essential that this directory is backed by a durable, persistent Docker volume or bind mount with appropriate backup schedules.

### 2. Fleet Trust Distribution
End users and microservices must have the CertSmith Root CA installed in their trust stores before they can consume issued certificates without warnings. Trust distribution should be integrated into:
- Ansible playbooks or Puppet/Chef recipes for bare-metal and VMs.
- Docker base images or Kubernetes startup DaemonSets.
- Windows Active Directory Group Policy Objects (GPOs) for office workstations.

### 3. Key Rotation & Expiry Management
While end-entity certificates renew automatically every 60–90 days via ACME, the intermediate CAs (valid for 3 years) and Root CA (valid for 10 years) require planned lifecycle rotations.
